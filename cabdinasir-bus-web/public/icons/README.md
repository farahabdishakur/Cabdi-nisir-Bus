# Icon-ka app-ka

`icon.svg` waa icon ku-meel-gaar ah (bas casaan + "CB"). Marka icon-ka dhabta ah la helo:

1. Sawir PNG ah oo **1024×1024** (gees kasta wax muhiim ah ha ku jirin ~10% — taleefannada qaar way gooyaan).
2. U dir Claude → wuxuu sameynayaa cabbirrada: `icon-192.png`, `icon-512.png`, `maskable-512.png`, `apple-touch-icon.png` (180), `favicon-48.png`.
3. Haddii la beddelo, `public/sw.js` → `VERSION` kordhi (tusaale `cb-v4`) si kombiyuutarada hore icon-ka cusub u helaan.
